# Publishing this source repository

[Back to README](../README.md)

The project is prepared for a **source-only public GitHub repository**. It has no required prebuilt firmware or release archive: new users build locally and copy the HA component from source.

## Included and excluded files

Keep these source files:

- `README.md`, `README.hu.md`, public `docs/` and both languages' SVG/PNG wiring diagrams.
- `config.example.json` with placeholders only.
- Firmware C/headers/HTML, CMake files, `sdkconfig.defaults`, `partitions.csv`, component manifest and `dependencies.lock`.
- HA component, translations, tests and test requirements.
- Helper scripts, portable VS Code task definitions and `settings.example.json`.

`.gitignore` excludes:

| Path/pattern | Reason |
|---|---|
| `config.local.json`, `*.local.*`, `.env*` except `.env.example` | Private values |
| `provisioning/` | CSV and NVS image contain credentials |
| `*.bin`, `*.elf`, `*.map`, `*.o`, `*.a` | Generated firmware/build artifacts |
| `dist/` | Local firmware/HA release packages and checksums |
| `firmware/build*/`, `managed_components/`, generated `sdkconfig` | Regenerated by IDF from committed source/defaults/lockfile |
| `.tools/`, `.venv*/`, Python/test caches | Local SDK/runtime dependencies |
| `firmware/.vscode/settings.json` | Personal SDK/compiler/serial paths; keep the example instead |
| `docs/VERIFICATION.md` | Internal device-specific development log; public validation guidance is in `TESTING.md` |
| OS/editor temporary files, logs, private key files | Local/generated data |

PNG/SVG diagrams are intentionally included. The firmware `.bin` exclusion does not exclude documentation images.

## Check what Git will upload

From the repository root:

```sh
git status --short
git check-ignore -v config.local.json provisioning/nvs.bin firmware/build/gas_reader.bin dist/example.bin
```

The second command should report matching ignore rules. Never force-add those files. Ignore rules do not remove files already tracked in an older repository; if applicable, remove only their tracked copy with `git rm --cached -- <path>` and handle any previously published secrets separately.

Use a Git workflow or GitHub Desktop so ignore rules are applied. Uploading a raw copy of the whole working folder through a browser/ZIP can include ignored local files; do not use the entire working directory as a source archive.

## First commit and push

Create an **empty public repository** on GitHub, without an auto-generated README/initial commit. Choose a license and add a `LICENSE` file when you have selected the intended license; none is assigned automatically by these preparation steps.

For this local repository, after reviewing the files:

```sh
git add .
git diff --cached --stat
git diff --cached --name-only
```

The following command should produce no paths:

```sh
git ls-files -- '*.bin' 'config.local.json' 'provisioning/*' 'dist/*' 'firmware/.vscode/settings.json' 'docs/VERIFICATION.md'
```

Then commit and push, replacing `YOUR_USERNAME` and the repository name:

```sh
git commit -m "Prepare Gas Reader source and documentation"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/gas-reader.git
git push -u origin main
```

If `origin` already exists, inspect it and use the appropriate remote instead of adding it twice. GitHub authentication is handled by your local Git/GitHub credential setup; do not put a token in source files or in a committed URL.

## Reproducing a fresh checkout

The repository must work without `dist/`, local configuration, SDK caches or generated build files:

1. Install/select the documented IDF version.
2. Copy the public config template to the ignored local filename and enter your own values.
3. Build; generate initial NVS locally.
4. Install HA from `homeassistant/custom_components/gas_reader`.
5. Follow the first-install and hardware-validation guides.

Optional `python3 tools/package.py` recreates local release artifacts after a build. Keep them ignored; this workflow does not require uploading firmware binaries to GitHub.
